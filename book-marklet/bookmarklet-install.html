Step 2 — How to use it

1. Open a recipe page in any tab
2. Tap 🥄 Save Recipe Ingredients from your bookmarks
3. Confirm the popup — your dashboard opens in a new tab with ingredients pre-loaded
4. Go back, repeat for more recipe tabs
5. On the dashboard, select recipes → 🛒 Grocery List — all pre-filled

How it works

Runs in the recipe tab (so it can read the page freely). Tries three methods: JSON-LD structured data → CSS class selectors → text heuristics. Sends ingredients to the dashboard via a URL parameter — no server, no API key needed.

Works on: AllRecipes, Food Network, NYT Cooking, Serious Eats, Bon Appétit, Epicurious, Tasty, The Kitchn, Simply Recipes, Delish, Tasting Table, and most WordPress recipe sites.
