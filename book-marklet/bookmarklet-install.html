🔖 Recipe Ingredients Bookmarklet

This bookmarklet scrapes ingredients from any recipe page and saves them to your dashboard automatically — no copy-paste needed.

STEP 1 — Install the bookmarklet

On iPad Firefox:
1. Tap the link below and hold → Add Bookmark
2. Save it to your bookmarks bar
3. Edit the bookmark — delete everything in the URL field and paste in the code below
Firefox on iOS doesn't let you drag bookmarklets directly, so you need to bookmark any page first, then edit the URL to the bookmarklet code.
On desktop (Chrome / Firefox / Safari):
Drag the button below to your bookmarks bar
🥄 Save Recipe Ingredients

STEP 2 — Use it

1. Open a recipe page in any tab
2. Tap 🥄 Save Recipe Ingredients from your bookmarks
3. You'll see a confirmation: "✓ 12 ingredients saved"
4. Repeat for as many recipe tabs as you want
5. Switch to your Recipe Dashboard → select the recipes → click 🛒 Grocery List — ingredients are pre-filled automatically

HOW IT WORKS

The bookmarklet runs in the recipe tab (so it can read the page freely — no CORS issues). It tries three methods in order:

1. JSON-LD schema data — works on ~80% of major recipe sites
2. DOM selectors — targets common recipe plugin class names
3. Text heuristic — finds ingredient-looking lines near the word "Ingredients"

Data is stored in localStorage, which is shared between tabs on the same domain. When you open the Grocery List on the dashboard, it checks for saved ingredients automatically.

SITES THAT WORK WELL

AllRecipes, Food Network, NYT Cooking, Serious Eats, Bon Appétit, Epicurious, Tasty, The Kitchn, Simply Recipes, Delish, Tasting Table, and most WordPress recipe sites (WP Recipe Maker, Tasty Recipes, etc.)
